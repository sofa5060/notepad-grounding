# Milestones 1-2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the initial uv Python project and a Windows screenshot annotation proof.

**Architecture:** Keep the first proof deterministic and inspectable. The CLI captures the Windows desktop, writes a raw screenshot, draws fixed coordinate reference boxes and metadata, then writes an annotated image for coordinate sanity checks before OCR or candidate detection exists.

**Tech Stack:** Python 3.11+, uv, Pillow for annotation, mss for screenshot capture, pytest for focused unit tests.

```python
from PIL import Image

from notepad_grounding.grounding.annotations import Box, annotate_screenshot


def test_annotate_screenshot_draws_boxes_without_resizing(tmp_path):
    image = Image.new("RGB", (120, 80), "white")
    boxes = [Box(10, 10, 40, 30, "sample")]

    output_path = tmp_path / "annotated.png"
    result = annotate_screenshot(image, boxes=boxes, output_path=output_path)

    assert result == output_path
    assert output_path.exists()

    annotated = Image.open(output_path)
    assert annotated.size == (120, 80)
    assert annotated.getpixel((10, 10)) != (255, 255, 255)
```
